# ugN2N
一个N2N前端GUI联机程序

ugN2N 为闭源免费软件，仅提供编译后的可执行程序（EXE），不开放源代码。
谢绝反编译、逆向、修改、二次打包、倒卖本程序。
允许个人非商用使用。
大厅服务器由作者兴趣使然公益托管，如有恶性bug请反馈，作者会择机修复

# ugN2N 客户端使用说明

## 一、安装

1. **安装 TAP 虚拟网卡驱动（必需）**
   首次使用前请安装 OpenVPN 的 `tap-windows6` 驱动：
   <https://github.com/OpenVPN/tap-windows6/releases>
   或安装压缩包内自带的tap驱动文件
   
   安装后建议重启一次。若未安装，程序会提示
   `No Windows tap devices found, did you run tapinstall.exe?`。

3. **保持文件完整**
   把整个 `ugN2N` 文件夹解压到任意位置，不要只复制 `client.exe`：

   ```text
   ugN2N/
     client.exe
     edge.exe          # n2n 客户端
     supernode.exe     # 免登录本地房间的中继
     client.json
   ```

4. **双击 `client.exe`**
   程序会请求管理员权限（创建虚拟网卡需要），然后自动打开浏览器界面。
   界面只在本机 `127.0.0.1` 上提供，不对外开放。
   `edge.exe`、`supernode.exe` 与浏览器助手均隐藏窗口运行，不会弹出黑色命令行窗口。

5. **重复双击不会开多个**
   同一时间只允许一个客户端实例。再次双击 `client.exe` 会直接打开已运行实例的本地页面，
   不会启动第二套 edge/supernode，也不会重复请求管理员权限。

> 如果 Windows 防火墙弹窗，请允许程序访问网络。

## 二、中央大厅联机

中央连接已内置，界面不会显示、也不能填写服务器域名、IP 或端口。

1. 打开客户端后，使用邀请码注册并登录（密码至少 8 位）；没有邀请码可点击「申请邀请码」填写邮箱，等待超级管理员审核。
2. 登录后顶部会显示全站公告；若管理员开启了推广，右下角会出现可点击的悬浮窗。
3. 左侧是公开房间列表，右侧显示在线玩家和全局聊天。管理员账号还可以在玩家列表/房间成员里踢人（目标 15 分钟内无法登录）。
4. 点击「创建」填写房间名与可选密码，即可建房。
5. 把 **6 位房间号**发给朋友；朋友输入房间号（有密码则填写密码）加入。
6. 进入房间后可看到成员、虚拟 IP、房间聊天；同一房间的成员可以像在同一局域网内互相访问。
7. 房主可「解散房间」，成员可「离开房间」；最后一人离开后房间自动销毁。

> 登录后请等顶部显示「大厅已连接」再创建/加入房间。

## 三、免登录本地房间

适合不想注册账号、或双方都能直连的场景。房主需要有一个朋友能访问到的外网地址。

**房主：**

1. 首页切到「免登录 · 自建房间」。
2. 填写昵称、房间名；公网联机时填写对外 IP/域名，局域网可留空。
3. 点击「启动本地房间」。客户端会自动启动本机的 `supernode.exe`、`edge.exe`
   和本地控制服务（默认 TCP `17891`）。
4. 把「邀请好友」地址（例如 `192.168.1.10:17891`）发给朋友。

**加入者：**

1. 切到「免登录 · 自建房间」。
2. 填写房主给的 `IP:端口` 和昵称，点击加入。
3. 客户端会自动获取 n2n 参数并启动本机 `edge.exe`。

**公网联机注意：**

- 房主需要在路由器/防火墙放行 **TCP 控制端口（默认 17891）** 和
  **UDP/TCP 中继端口（默认 27777）**。
- 如果房主处于运营商 NAT 后方，端口映射可能不可用，建议改用中央大厅。
- 房主关闭房间后，加入者会在数秒内自动退出。

## 四、常见问题

**提示找不到 edge.exe / supernode.exe**
确认三个 exe 与 `client.json` 在同一目录，且文件名没有被杀毒软件改名/隔离。

**edge 启动后立刻退出 / 没有虚拟网卡**
多为 TAP 驱动未安装或未以管理员运行；打开界面里的「运行日志」查看真实报错。

**想修改本地端口**
编辑 `client.json` 中的 `ui_port`、`control_port`、`supernode_port`，重启客户端。
配置中不含也不应填写中央服务器地址；程序不会把该地址写入文件或界面。

**注册需要邀请码？**
是的。邀请码为 12 位大小写英文字母和数字，一次性使用且区分大小写。没有邀请码可在登录页申请；审核由超级管理员在服务端控制台完成。

**能否连接自建服务器？**
正式版固定连接官方服务端，且不会显示其域名/IP/端口。自建服务器请自行从源码编译，并在调试时使用隐藏的 `-server` 参数。

**双击没反应 / 只打开页面**
说明已有实例在运行，新启动的进程只负责打开本地管理页面，这是预期行为。

## 五、卸载

1. 在界面中退出大厅/关闭本地房间并退出程序。
2. 删除整个 `client` 文件夹。
3. 如需彻底移除虚拟网卡，可在「设备管理器」卸载 TAP-Windows 适配器；
   不再使用本项目时可同时卸载 `tap-windows6` 驱动。
