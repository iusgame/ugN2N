## ugN2N 客户端使用说明
### 一、安装前置与部署
1. **安装 TAP 虚拟网卡驱动（必需）**
首次运行前需要 `tap-windows6` 驱动（OpenVPN 官方驱动）
驱动下载：https://github.com/OpenVPN/tap-windows6/releases
也可以直接使用压缩包内自带驱动安装包。

安装驱动后建议重启电脑；未安装驱动启动程序会报错：
`No Windows tap devices found, did you run tapinstall.exe?`

2. **文件结构不要拆分**
将整个 ugN2N 文件夹完整解压到本地任意目录，**不要单独提取 client.exe 运行**
    
  目录结构参考：    
  ugN2N/    
    client.exe    
    edge.exe # n2n 底层客户端程序    
    supernode.exe # 本地自建房间中继服务    
    client.json # 本地配置文件    

          

3. **启动方式**
双击 `client.exe`，程序会申请管理员权限（创建虚拟网卡必须），随后自动在浏览器打开本地管理页面。
管理页面仅监听本机 `127.0.0.1`，外部网络无法访问。
edge.exe、supernode.exe、本地后台服务均后台静默运行，不会弹出黑框控制台。

4. **单实例限制**
同一台电脑同时仅能运行一个客户端实例；重复双击 client.exe 只会唤起已运行程序的管理页面，不会重复启动服务、重复申请权限。

> Windows 防火墙弹出提示时，请允许程序通行。

### 二、中央大厅联机（推荐）
大厅服务内置在程序内，界面不展示、不支持手动填写服务端 IP / 域名 / 端口

1. 打开管理页面，使用邀请码注册账号登录，密码长度最少 8 位；没有邀请码可在登录页提交邮箱申请，等待管理员人工审核。
2. 登录顶部可见全站公告；若开启推广功能，右下角会显示悬浮提示。
3. 左侧：公开房间列表；右侧：在线用户列表 + 全局聊天。管理员账号支持房间内踢人，被踢出用户 15 分钟内无法重新登录。
4. 点击【创建房间】，填写房间名称，可选择设置房间密码，创建联机房间。
5. 将 6 位房间号分享给好友，好友输入房间号 + 房间密码（有密码时）即可加入。
6. 进入房间后，可以查看房间成员、成员虚拟局域网 IP、房间内私聊；同一房间内所有设备处于同一个二层局域网，支持老游戏局域网发现。
7. 房主可手动解散房间，普通成员可主动退出房间；房间内最后一名成员离开后，房间自动销毁。

> 注意：必须等待页面顶部提示【大厅已连接】成功后，再创建或者加入房间。

### 三、免登录・本地自建房间
适合不想注册账号、点对点直连联机的场景；房主需要提供可被好友访问的通信地址。

**房主操作**
1. 切换页面到「免登录・自建房间」标签页
2. 填写昵称、房间名称；公网对外联机填写自身公网 IP / 域名，仅内网联机可留空
3. 点击【启动本地房间】，程序自动拉起本机 supernode.exe、edge.exe 和本地控制服务，默认控制端口 TCP:17891
4. 将页面生成的好友访问地址（示例：`192.168.1.10:17891`）发给联机伙伴

**加入者操作**
1. 同样切换到「免登录・自建房间」
2. 填写房主发来的 `IP:端口`、自己的昵称，点击加入
3. 客户端自动拉取组网参数，启动本机 edge 接入局域网

⚠️ 公网自建房间重要提醒：
- 房主路由器 / 防火墙需要放行：TCP 控制端口 17891，中继 UDP 端口 27777
- 如果房主在 CGNAT 内网，无法做端口映射，自建房间大概率无法连通，优先使用中央大厅联机
- 房主关闭房间后，所有加入端会在数秒内自动断开组网

### 四、常见问题 FAQ
- **提示找不到 edge.exe/supernode.exe**
检查文件完整性，确认所有文件在同一个文件夹；大概率是杀毒软件隔离 / 重命名了 exe 文件，需要添加白名单。

- **edge 启动瞬间退出、无虚拟网卡**
优先排查两点：TAP 驱动未正确安装、程序没有管理员权限；可以打开页面内【运行日志】查看原始报错信息。

- **自定义本地端口**
直接编辑 `client.json`，修改 `ui_port`、`control_port`、`supernode_port` 参数，保存后重启客户端生效。
中央大厅服务地址内置固化，配置文件不包含、也不能修改大厅服务地址。自建独立服务端，需要拿到源码编译，使用隐藏 `-server` 调试参数。

- **注册必须邀请码？**
是的。邀请码为 12 位大小写字母 + 数字，一次性消耗、区分大小写。无邀请码可以在登录页面提交申请，等待管理员审核。

- **双击程序没反应，直接打开网页**
属于正常逻辑：程序已经在后台运行，本次启动仅唤起浏览器管理页面。

### 五、卸载步骤
1. 先在管理页面退出房间、停止服务，正常关闭客户端
2. 删除整个 ugN2N 文件夹
3. 如需彻底清理虚拟网卡：Windows 设备管理器里卸载 TAP-Windows 适配器；完全不再使用可以一并卸载 tap-windows6 驱动
